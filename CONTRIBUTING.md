# Contributing to AETHERA

## Original work only

This is an original creature RPG. It is **not** a Pokémon fangame.

Do **not** contribute:

- Official or ripped sprites, tiles, fonts, music, cries, or UI chrome
- Pokémon / Pokédex / Poké Ball names, maps, or dialogue
- ROM files or patches (`.gba`, `.ips`, `.bps`, …)
- Pokémon Essentials / PSDK data dumps
- “Fakemon” that are silhouette clones of official species
- Assets generated by a model trained specifically to reproduce Nintendo sprites

If you are unsure, do not add it.

## How we work

1. Read `MASTER_LOG.md`. Do **one phase** at a time.
2. Do not mark a phase done unless its Exit Gate passes.
3. Update `MASTER_LOG.md` when you finish.
4. All game data is resources / JSON — not magic numbers in the battle loop.
5. Tests (GUT) must stay green.

## Running locally (offline)

See `PLAY_OFFLINE.md`. Short version:

```bash
./scripts/fetch-godot.sh    # once, needs network
./scripts/play.sh           # after that, fully offline
```

Saves go in `saves/` next to the repo (portable mode).

## Code style

- GDScript, `snake_case` functions, `PascalCase` class_name
- IDs are `StringName` slugs (`reedling`, `move_pulse_tap`)
- No god-object autoloads
