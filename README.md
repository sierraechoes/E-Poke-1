# AETHERA (codename ECHOES)

An original, **fully offline** open-source creature RPG.

Not a Pokémon ROM. Not a ROM hack. Not a Nintendo-IP fangame.

| | |
|---|---|
| Public title | **AETHERA** |
| Engine | Godot **4.6.3** (standard) |
| Phase | **P02 done · P03 ready** |
| Live schedule | [MASTER_LOG.md](MASTER_LOG.md) |
| How to play offline | **[PLAY_OFFLINE.md](PLAY_OFFLINE.md)** |

## Launch after you download this folder

```bash
./scripts/fetch-godot.sh    # once, needs network
./scripts/play.sh           # forever after: offline
```

Windows: `scripts\fetch-godot.ps1` then `scripts\play.bat`.

Saves are in `saves/` next to the project. Copy the folder, keep your files.

## Keys

Z / Enter confirm · X / Esc back · arrows move · S save (in Field Camp)
