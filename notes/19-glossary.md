# 19 — Glossary

> Short definitions used across the notes. For humans joining the repo cold.

| Term | Meaning |
|---|---|
| **ROM** | Dump of a cartridge. Copyrighted. We do not store these. |
| **ROM hack** | Modified official game, usually shipped as a BPS patch |
| **Fangame** | Standalone PC game, usually Essentials/PSDK, usually still Nintendo IP |
| **Binary hacking** | Editing a compiled `.gba` with tools |
| **Decomp** | pret's matching C/asm source that rebuilds an official ROM |
| **pret** | Pokémon Reverse Engineering Tools. GitHub org behind pokeemerald etc. |
| **pokeemerald-expansion** | RHH kit: modern battle engine on Emerald decomp |
| **CFRU / DPE** | C-injection kits that modernize FireRed binary hacks |
| **BPS / IPS / UPS** | Patch formats. Player applies them to a clean ROM |
| **Essentials** | Ruby + RPG Maker XP Pokémon fangame kit (Maruno) |
| **PSDK / Studio** | Pokémon Workshop's modern kit + database GUI |
| **PBS** | Plain-text database files in Essentials |
| **Fakemon** | Fan-original creature. Still often shipped *inside* a Pokémon game |
| **Field / Field Effect** | Reborn's place-as-ruleset. Our Resonance Field |
| **HM slave** | A party member wasted on overworld moves. We will not have these |
| **ADM** | Unbound's key item that invokes HMs without teaching them |
| **BST** | Base stat total |
| **IV / EV** | Hidden genes / training points. We will replace or surface them |
| **STAB** | Same-type attack bonus (usually 1.5×) |
| **Physical/special split** | Move category is per-move, not per-type (Gen 4+) |
| **Nuzlocke / Iron** | Permadeath challenge rules |
| **Kaizo** | Extremely hard, puzzle-fight ROM hack genre |
| **Attune / Pact** | ECHOES catch analogue |
| **Echo** | ECHOES creature |
| **Silence Zone** | Biome collapsed by over-harvest |
| **Overdraw** | ECHOES gimmick: spend Bond to rewrite a Field |
| **Inspector** | ECHOES gym analogue |
| **Almanac** | ECHOES dex |
| **QoL** | Quality of life (run indoors, fast text, reusable TMs…) |
| **Vertical slice** | Smallest playable piece that proves the fantasy |
| **AETHERA** | Public working title |
| **MASTER_LOG** | Living phase checklist at repo root; source of truth for status |
| **P00–P30** | One-prompt build phases through 1.0 |
| **Exit Gate** | Tests + playable check that must pass before the next phase |
| **GUT** | Godot Unit Test addon; our headless harness |
| **Scar / Training / Temper** | Our IV / EV / Nature analogues (visible) |
